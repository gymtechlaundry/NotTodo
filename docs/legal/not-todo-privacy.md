# Privacy Policy — Not ToDo

Live page: https://hyperionappstudio.com/nottodo/privacy/

Mirror of the public policy. Edit the website copy, then keep this file in sync.

Not ToDo is operated by Hyperion App Studio. The store listing is grandfathered under bundle ID `com.darcsoftware.nottodo`. The app does not collect personal information. Items, fail counts, reminder preference, and optional app-lock preference stay on the device. Optional Face ID / fingerprint / device passcode unlock is handled by the operating system; we do not receive biometric data. Local notifications stay on the device. There is no account, analytics SDK, or advertising.

Contact: support@hyperionappstudio.com

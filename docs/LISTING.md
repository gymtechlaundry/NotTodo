## Full description

```
Not ToDo is a list of things you should not do.

Add the habits you are trying to avoid. Every time you slip, tap the item to update the count. Stats show where you slip most. Optional daily reminders nudge you to stay off the list. Optional app lock uses Face ID, fingerprint, or your device passcode so the list stays private if someone else opens your phone.

No account. No cloud. Your list stays on the device.
```
